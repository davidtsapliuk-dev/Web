# Чек-лист сдачи сайта (Германия)

Проходить перед запуском **каждого** сайта. Около 15–20 минут.
Пункты с ⚖️ — частые причины Abmahnung, их пропускать нельзя.

> Это рабочий чек-лист, а не юридическая консультация. Тексты Impressum, Datenschutz и AGB
> берите из генератора (e-recht24.de, IT-Recht Kanzlei) или у юриста.

---

## 1. Юридическое ⚖️

- [ ] **Impressum** есть, открывается с каждой страницы максимум за 2 клика (ссылка в подвале).
      Имя/фирма, адрес (не абонентский ящик), e-mail, телефон или второй быстрый канал связи,
      USt-IdNr. (если есть), регистр и номер (если GmbH/UG), ответственный за контент.
- [ ] **Datenschutzerklärung** есть, ссылка в подвале, и в ней описано **всё**, что реально
      используется: хостинг, форма, сервис формы, аналитика, шрифты, cookie-баннер, встраивания.
- [ ] Тексты Impressum/Datenschutz сгенерированы или проверены (дата: ________).
- [ ] Для интернет-магазина: AGB, Widerrufsbelehrung (право на отказ), кнопка
      «zahlungspflichtig bestellen», цены с MwSt и стоимостью доставки. Старую ссылку на
      ODR-платформу ЕС убрать (платформа закрыта 20.07.2025) — сверьте с генератором текстов.
- [ ] С клиентом подписан **AVV** (договор обработки данных), если вы хостите сайт
      или получаете заявки его клиентов.
- [ ] У хостинга / сервиса формы есть AVV/DPA, серверы в ЕС или есть законное основание передачи.
- [ ] Права на все фото, иконки, шрифты и тексты есть (лицензии сохранены в проекте).
      Фото из Google без лицензии — классический Abmahnung.

## 2. DSGVO и cookies ⚖️

- [ ] Открыть сайт с DevTools → Network: **нет запросов к чужим серверам** до согласия
      (Google Fonts, Google Maps, YouTube, Facebook, CDN со скриптами).
- [ ] Шрифты лежат на своём сервере.
- [ ] Если есть необязательные cookies или трекинг — включён баннер (`consent.js`):
  - [ ] «Ablehnen» так же заметна, как «Akzeptieren»
  - [ ] до согласия ничего не грузится
  - [ ] в подвале есть «Cookie-Einstellungen»
- [ ] Если cookies/трекинга нет — баннер выключен, в Datenschutz это так и описано.
- [ ] YouTube/карты — только через «двухкликовое» встраивание (сначала заглушка, потом согласие).
- [ ] Форма: галочка согласия со ссылкой на Datenschutz, собираем только нужные поля.
- [ ] Защита от спама без Google reCAPTCHA (honeypot уже есть; при необходимости Friendly Captcha).

## 3. Безопасность

- [ ] HTTPS работает, http:// перенаправляет на https://.
- [ ] Заголовки безопасности подключены (`_headers` для Netlify/Cloudflare, `vercel.json` для Vercel).
      Если добавили внешний сервис — внесли его в Content-Security-Policy.
- [ ] Проверки на живом сайте, цель — оценка **A** или выше:
  - [ ] https://securityheaders.com
  - [ ] https://developer.mozilla.org/en-US/observatory
  - [ ] https://www.ssllabs.com/ssltest/
- [ ] В коде и репозитории нет паролей, API-ключей, `.env` (попросите Claude проверить).
- [ ] Зависимости без известных уязвимостей (`npm audit`, если есть package.json).
- [ ] Форма проверяется **на сервере** (длина, формат, лимит запросов), а не только в браузере.
- [ ] `/.well-known/security.txt` с актуальным контактом и датой.
- [ ] Для WordPress/CMS: автообновления, 2FA для админки, нестандартный логин, минимум плагинов,
      ежедневные бэкапы.
- [ ] Доступы клиента (хостинг, домен, CMS) — в менеджере паролей, 2FA включена везде.

## 4. Техническое качество

- [ ] Проверено на телефоне, планшете, ноутбуке; нет горизонтальной прокрутки.
- [ ] Chrome, Safari, Firefox.
- [ ] PageSpeed Insights: 90+ на мобильных.
- [ ] Все ссылки работают, нет 404. Есть своя страница 404.
- [ ] Форма реально доставляет заявку (отправить тестовую).
- [ ] `<title>` и `description` на каждой странице, favicon, превью для соцсетей (Open Graph).
- [ ] `robots.txt` и `sitemap.xml`; сайт не закрыт от индексации после разработки.
- [ ] Доступность: контраст, подписи у полей, alt у картинок, работа с клавиатуры.
- [ ] Язык страницы указан верно (`<html lang="de">`).

## 5. Передача клиенту

- [ ] Домен, хостинг, аккаунты оформлены **на клиента**.
- [ ] Передан доступ и короткая инструкция по редактированию.
- [ ] Настроены бэкапы и мониторинг доступности (например UptimeRobot).
- [ ] Согласован срок поддержки и что делать при сбое.
- [ ] Финальный счёт (Rechnung) с правильными реквизитами; при Kleinunternehmerregelung —
      пометка «Gemäß § 19 UStG wird keine Umsatzsteuer berechnet».
